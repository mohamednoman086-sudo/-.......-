نظام أحمد — الموسيقى الكاملة وتسجيل الدخول بجوجل
================================================

تشغيل الموقع
1) فك ضغط الملف.
2) افتح مجلد نظام_أحمد في Visual Studio Code.
3) شغّل index.html باستخدام Live Server (لا تفتحه مباشرة عبر file:// لأن Google Login يحتاج localhost أو HTTPS).

تشغيل الأغاني كاملة داخل الموقع
- ألصق رابط فيديو YouTube في خانة «تشغيل أغنية كاملة برابط YouTube»، ثم اضغط «تشغيل كامل». الفيديو يعمل داخل الموقع بمشغّل YouTube الرسمي، مع تحكم الصوت والتقديم من المشغّل نفسه.
- للبحث عن نتائج YouTube مباشرة داخل الموقع، يلزم إضافة YouTube Data API key في config.js (الحقل YOUTUBE_API_KEY). من Google Cloud Console أنشئ مشروعًا، فعّل YouTube Data API v3، وأنشئ API key مع تقييد الاستخدام على YouTube Data API v3.
- بدون المفتاح، يظل كتالوج Apple/iTunes للمعاينات الصوتية متاحًا. هذه المعاينات قد تكون قصيرة ولا تتيح الأغنية كاملة. لا يوجد مصدر عام قانوني يضمن تشغيل كل الأغاني كاملة كملفات MP3؛ مشغّل YouTube يشغّل الفيديوهات التي يسمح أصحابها بتضمينها، وقد يمنع بعض الفيديوهات أو يقيّدها حسب البلد.

إعداد تسجيل الدخول الحقيقي بحساب Google (مرة واحدة)
1) افتح https://console.firebase.google.com/ وأنشئ مشروع Firebase.
2) من إعدادات المشروع Project settings > General أضف Web App، وانسخ بيانات firebaseConfig.
3) افتح config.js وضع القيم apiKey وauthDomain وprojectId وappId داخل AHMED_CONFIG.FIREBASE. لا تضع مفاتيح خاصة بالخادم أو كلمات مرور هنا.
4) من Firebase Authentication > Sign-in method فعّل Google واحفظ التغييرات.
5) من Authentication > Settings > Authorized domains تأكد أن localhost موجود. عند النشر أضف نطاق موقعك الحقيقي مع HTTPS.
6) شغّل الموقع باستخدام Live Server ثم اضغط «تسجيل الدخول بجوجل» واختبره.

الخصوصية والملاحظات
- لا يطلب الموقع كلمة مرور Google. المصادقة تتم عبر Firebase ونافذة Google الرسمية.
- تسجيل الدخول هنا يثبت هوية المستخدم في هذه الواجهة؛ مزامنة مهام الدراسة والنقاط بين الأجهزة تحتاج قاعدة بيانات مثل Firestore وقواعد أمان مناسبة، وليست مفعّلة تلقائيًا.
- البحث داخل YouTube يحتاج API key؛ لا تشارك مفتاحًا غير مقيّد. قيّد المفتاح من Google Cloud Console.
- باقي وظائف المنظم موجودة، وبيانات الدراسة المحلية محفوظة في المتصفح الحالي.
